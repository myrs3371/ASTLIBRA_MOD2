## 方案结论

最终方向：

```text
ASTLIBRA.ModLoader.exe + Mod DLL
```

Proxy DLL / DLL 劫持只作为快速原型的可能加载入口，不作为最终发布架构。正式分享时需要版本检查、配置、日志、启用/禁用和卸载能力。

## 今天的学习内容

第一步不做 Hook、不做注入，只学习创建一个最小 C++ DLL，让 DLL 被加载时写入日志。

Visual Studio 设置：

```text
项目类型：动态链接库 (DLL)
项目名称：AstlibraMod
平台：x64
配置：Release
```

第一版测试代码：

```cpp
#include <windows.h>
#include <fstream>

DWORD WINAPI ModThread(LPVOID)
{
    std::ofstream log("AstlibraMod.log", std::ios::app);
    log << "AstlibraMod loaded successfully\n";
    log.close();
    return 0;
}

BOOL APIENTRY DllMain(HMODULE hModule, DWORD reason, LPVOID reserved)
{
    if (reason == DLL_PROCESS_ATTACH)
    {
        DisableThreadLibraryCalls(hModule);
        CreateThread(nullptr, 0, ModThread, nullptr, 0, nullptr);
    }
    return TRUE;
}
```

编译后预期得到：

```text
x64\Release\AstlibraMod.dll
```

今天暂时不要把 DLL 放进游戏目录，也不要启动注入工具，先完成编译即可。

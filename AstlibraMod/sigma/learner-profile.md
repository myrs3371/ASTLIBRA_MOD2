# Learner Profile

Updated: 2026-10-02

## Learning Style

- Preferred explanation mode: inline, purpose-first explanations that split unfamiliar C++ declarations into individual syntax components.
- Pace: project-first and efficient; provide one small concrete code edit at a time, then continue after the learner completes it.
- Responds best to: direct instructions with brief purpose-first explanations; avoid repeated Socratic checks and verbose question-answer rounds.
- Struggles with: receiving a full implementation before understanding each part.

## Misconception Patterns

- Initially treats `case` labels as isolated blocks; needs executable counter-examples to reinforce fall-through behavior.
- Relative-path reasoning improves quickly when connected to the program's working directory.
